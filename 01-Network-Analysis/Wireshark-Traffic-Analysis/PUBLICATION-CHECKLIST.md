# Evidence handling and publication checklist

Before committing evidence to a public repository:

- [ ] I am authorized to use and publish this dataset.
- [ ] No credentials, tokens, cookies, personal data, or private messages are present.
- [ ] Internal hostnames, MAC addresses, and identifying IP addresses are redacted where appropriate.
- [ ] Screenshots show only the relevant packets and fields.
- [ ] Raw PCAP/PCAPNG files are omitted unless publication is explicitly authorized and the file has been reviewed.
- [ ] Findings are reproducible and tied to frame numbers/timestamps.
- [ ] Observed facts are distinguished from hypotheses.
- [ ] No real third-party system was scanned or accessed without authorization.

When in doubt, publish a sanitized screenshot and a written explanation rather than the original capture.
