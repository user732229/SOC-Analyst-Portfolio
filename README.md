# SOC Analyst Portfolio

Hands-on cybersecurity labs focused on SOC Tier 1 skills: network traffic analysis, alert triage, log investigation, phishing analysis, and incident response.

> **Ethics and safety:** All activities are performed in authorized training environments or on traffic/data generated by the author. Sensitive data, credentials, personal information, and unreviewed packet captures are never published.

## Portfolio roadmap

| Area | Focus | Status |
|---|---|---|
| Network analysis | Wireshark, DNS, TCP/IP, protocol inspection | In progress |
| Phishing analysis | Email headers, URLs, sender validation | Planned |
| Windows telemetry | Event logs and suspicious activity | Planned |
| Linux telemetry | Authentication and system logs | Planned |
| SIEM | Alert triage, queries, correlation | Planned |
| Incident response | Scope, containment recommendations, reporting | Planned |

## Documentation standard

Each lab should include:
1. Objective and authorized scope.
2. Environment and tools.
3. Investigation methodology.
4. Observations and evidence.
5. Analysis, limitations, and confidence.
6. Conclusion and recommended actions.
7. References.

Never fabricate findings. Clearly distinguish observed facts from hypotheses and conclusions.
